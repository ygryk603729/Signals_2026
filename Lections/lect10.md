### Тема: Коды БЧХ. Циклотомические классы. Построение порождающего полинома через минимальные многочлены. Примитивные и непримитивные коды БЧХ.

## 1. Конструктивный подход к построению кодов с заданным расстоянием

Коды БЧХ (Боуза–Чоудхури–Хоквингема) представляют собой важный подкласс циклических кодов, позволяющих гарантировать заданное минимальное расстояние d конструктивным способом, без полного перебора всех кодовых слов.

**Основная теорема БЧХ (конструктивная):**

Рассмотрим циклический код над полем GF(q) с порождающим полиномом g(x). Пусть α — примитивный элемент расширения GF(q^m). Если для некоторых целых чисел b ≥ 0 и d ≥ 2 выполняется условие:

g(α^(b+i)) = 0 для всех i = 0, 1, 2, …, d-2,

то минимальное расстояние кода не меньше d.

**Следствие для двоичных кодов (q = 2):**

Вследствие особенности характеристики поля (1+1=0) достаточно использовать только нечётные степени примитивного элемента. Для кода, исправляющего t ошибок (что соответствует d = 2t+1), порождающий полином имеет вид:

g(x) = НОК[ M₁(x), M₃(x), M₅(x), …, M_{2t-1}(x) ],

где M_i(x) обозначает минимальный многочлен элемента α^i.

## 2. Циклотомические классы

**Определение.**  
Пусть n = 2^m - 1 (для примитивных кодов). Циклотомическим классом показателя s называется множество, получаемое последовательным возведением в степень, равную характеристике поля (p=2):

C_s = { s, 2s, 4s, 8s, … }   (все операции по модулю n).

**Основные свойства циклотомических классов:**
- Различные классы не пересекаются.
- Элементы одного класса имеют одинаковый минимальный многочлен.
- В качестве представителя класса обычно выбирают наименьший элемент.

**Пример для n = 15 (m = 4):**

| Класс     | Элементы                    | Представитель |
|-----------|-----------------------------|---------------|
| C₀        | {0}                         | 0             |
| C₁        | {1, 2, 4, 8}                | 1             |
| C₃        | {3, 6, 12, 9}               | 3             |
| C₅        | {5, 10}                     | 5             |
| C₇        | {7, 14, 13, 11}             | 7             |

Видно, что все ненулевые элементы поля GF(2^4) разбиты на четыре класса.

## 3. Минимальные многочлены

**Определение.**  
Минимальным многочленом M_s(x) элемента α^s над полем GF(2) называется приведённый полином наименьшей степени с коэффициентами из GF(2), для которого α^s является корнем (т.е. M_s(α^s) = 0).

**Ключевые свойства:**
- M_s(x) неприводим над GF(2) (не раскладывается на множители с коэффициентами из GF(2)).
- Все элементы одного циклотомического класса имеют один и тот же минимальный многочлен.
- Любой полином, имеющий α^s корнем, делится на M_s(x) без остатка.

## 4. Порядок построения порождающего полинома g(x)

Алгоритм синтеза порождающего полинома для кода БЧХ с заданными параметрами:

1. Задать длину кода n (для примитивного кода n = 2^m - 1).
2. Построить все циклотомические классы по модулю n.
3. Определить требуемое конструктивное расстояние d = 2t + 1.
4. Выбрать последовательность степеней: α^b, α^(b+1), α^(b+2), …, α^(b+d-2). Обычно полагают b = 1.
5. Найти все циклотомические классы, имеющие непустое пересечение с выбранным набором степеней.
6. Взять минимальные многочлены представителей этих классов и вычислить их наименьшее общее кратное (НОК). Полученный полином и есть g(x).

**Примечание:** Фактическая размерность кода вычисляется как k = n - deg(g(x)). Реальное минимальное расстояние может оказаться больше конструктивного, но гарантированно не меньше d.

---

## 5. Практический пример: код БЧХ (15, 7, 5)

Рассмотрим построение кода, исправляющего две ошибки (t = 2), что соответствует d ≥ 5.

- Длина n = 15, следовательно m = 4.
- Выбираем b = 1. Набор корней: α^1, α^2, α^3, α^4.
- Определяем затронутые циклотомические классы:
  - α^1, α^2, α^4, α^8 относятся к классу C₁.
  - α^3, α^6, α^12, α^9 относятся к классу C₃.
- Порождающий полином: g(x) = M₁(x) · M₃(x).
- Степень g(x) равна сумме степеней минимальных многочленов: deg(M₁)=4, deg(M₃)=4, итого 8.
- Следовательно, k = 15 - 8 = 7. Код имеет параметры (n, k) = (15, 7).

**Сводная таблица для n = 15:**

| Используемые классы | Порождающий полином g(x) | k | Конструктивное d | Тип кода                   |
|---------------------|--------------------------|----|------------------|----------------------------|
| C₁                  | M₁(x)                    | 11 | 3                | Код Хэмминга (15,11)       |
| C₁ + C₃             | M₁(x)·M₃(x)              | 7  | 5                | Код БЧХ (15,7)             |
| C₁ + C₃ + C₅        | M₁·M₃·M₅                 | 5  | 7                | Код БЧХ (15,5)             |
| Все классы          | Произведение             | 1  | 15               | Код повторения (15,1)      |

## 6. Примитивные и непримитивные коды БЧХ

**Примитивные коды БЧХ:**  
Длина кода n = 2^m - 1, где m — степень расширения поля. Корни порождающего полинома выбираются среди степеней примитивного элемента α.

**Непримитивные коды БЧХ:**  
Длина кода n является делителем числа 2^m - 1, но n < 2^m - 1. Построение ведётся в том же расширении GF(2^m), но вместо α используется элемент β = α^r, где r = (2^m - 1)/n. При этом β имеет порядок n.

**Известный пример непримитивного кода: код Голея (23, 12, 7).**  
Число 23 делит 2^11 - 1 = 2047, поэтому код строится в поле GF(2^11) и является недвоичным в поле построения, но после ограничения на GF(2) даёт совершенный двоичный код.

---

## 7. Оценка размерности кода БЧХ

Для двоичных примитивных кодов БЧХ действует нижняя оценка на размерность:

k ≥ n - m·t,

где t — количество исправляемых ошибок, m — степень расширения поля.

Оценка следует из того, что порождающий полином собирает минимальные многочлены t разных классов, каждый степени не выше m.

## 8. Место кодов БЧХ в общей теории кодирования

**Связь с ранее изученными кодами:**
- Код Хэмминга (15, 11) является частным случаем кода БЧХ с t = 1.
- Код БЧХ (15, 7) — следующий шаг, исправляющий две ошибки.
- Код Рида–Соломона представляет собой частный случай недвоичного кода БЧХ с длиной n = q - 1 (где q = 2^m), достигающий границы Синглтона.

**Обобщение:**  
Добавление в проверочную матрицу строк с элементами α^(3i), α^(5i), α^(7i) и так далее систематически увеличивает число исправляемых ошибок по сравнению с кодом Хэмминга, сохраняя циклическую структуру.
