# Конспект лекции №7
## Обработка и интерпретация сигналов
### Тема: Циклические коды, полиномиальное представление и поля Галуа GF(2^m)

---

## 1. Приведённый (монический) полином

**Определение.**  
Полином P(x) называется приведённым (или моническим), если коэффициент при его старшей степени равен 1.

P(x) = x^k + a_{k-1} x^{k-1} + … + a_1 x + a_0

**Важное замечание.**  
В двоичном поле GF(2) коэффициенты могут быть только 0 или 1. Поэтому любой ненулевой полином в GF(2) автоматически является приведённым. Однако при переходе к расширенным полям GF(q) (где q > 2) это свойство становится критически важным для однозначного определения порождающего многочлена.

---

## 2. Порождающий многочлен g(x)

Циклический (n, k)-код полностью определяется своим порождающим многочленом g(x). Это единственный приведённый полином минимальной степени в коде.

**Свойства g(x):**
- Степень: deg(g(x)) = n − k (количество проверочных символов).
- Делимость: g(x) является делителем двучлена x^n − 1.
- Генерация: Любое кодовое слово c(x) — это результат умножения информационного блока m(x) на g(x):

c(x) = m(x) · g(x)   (mod x^n − 1),

где deg(m(x)) < k.

**Доказательство единственности.**  
Если бы существовало два приведённых полинома g₁(x) и g₂(x) одинаковой минимальной степени, то их сумма g₁(x) + g₂(x) также была бы кодовым словом. В GF(2) сложение коэффициентов происходит по модулю 2, поэтому старшие степени (1+1=0) сократятся, и мы получили бы кодовое слово меньшей степени, что противоречит условию минимальности.

**Пример.**  
В коде с кодовыми словами 000, 101, 011, 110 порождающий полином минимальной степени — 1 + x.

---

## 3. Делимость кодовых слов на g(x)

**Теорема.**  
Любое кодовое слово циклического кода делится на g(x) без остатка.

**Доказательство.**  
Любое кодовое слово c(x) степени, большей или равной deg(g(x)), можно представить как

c(x) = q(x) · g(x) + r(x),   deg(r(x)) < deg(g(x)).

Остаток r(x) также является кодовым словом (поскольку c(x) и q(x)·g(x) принадлежат коду). Но степень r(x) меньше степени g(x), что противоречит минимальности g(x), если r(x) ≠ 0. Следовательно, r(x) = 0.

---

## 4. Проверочный полином h(x)

Поскольку g(x) делит x^n − 1, существует полином h(x) степени k, такой что:

g(x) · h(x) = x^n − 1.

**Условие принадлежности коду.**  
Вектор является кодовым словом тогда и только тогда, когда при умножении на h(x) получается нулевой остаток по модулю x^n − 1:

c(x) · h(x) ≡ 0   (mod x^n − 1).

---

## 5. Построение циклических кодов

**Алгоритм построения:**
1. Зафиксировать длину n.
2. Разложить x^n − 1 на неприводимые множители над GF(2).
3. Выбрать любой неприводимый множитель в качестве g(x) (или произведение нескольких).
4. Получить циклический код с порождающим полиномом g(x).

**Пример (n = 7).**  
x^7 − 1 раскладывается на множители: (x+1)(x^3+x+1)(x^3+x^2+1). Один из порождающих полиномов — 1 + x + x^3 (код Хэмминга (7,4)). Другой — 1 + x^2 + x^3, который порождает эквивалентный код.

## 6. Расширение полей: Поля Галуа GF(2^m)

Для продвинутых кодов (БЧХ, Рида–Соломона) нам тесно в рамках 0 и 1. Мы расширяем поле до 2^m элементов.

**Как построить GF(2^m):**
- Выбираем неприводимый полином P(x) степени m (аналог простого числа в мире полиномов).
- Элементами поля становятся все полиномы степени меньше m.
- Арифметика: сложение — по модулю 2 (покомпонентное XOR), умножение — по модулю P(x).

**Пример: Поле GF(2^2), P(x) = x^2 + x + 1.**  
Элементы: 0, 1, x, x+1.

- Сложение: (x) + (x+1) = 1  (x + x = 0, 0+1 = 1).
- Умножение: x·x = x^2. Так как x^2 + x + 1 = 0, то x^2 = x + 1. Значит, x·x = x + 1.
- Обратный элемент: Для x обратным будет x+1, так как x·(x+1) = x^2 + x = (x+1) + x = 1.

**Замечание.**  
Поля GF(2^m) часто обозначаются как GF(2^m). Их элементы удобно представлять двоичными векторами длины m, где каждый бит соответствует коэффициенту полинома.

## 7. Минимальные многочлены и сопряжённые элементы

**Определение.**  
Минимальным многочленом элемента β ∈ GF(2^m) называется приведённый полином M(x) с коэффициентами из GF(2) минимальной степени, для которого β является корнем: M(β) = 0.

**Свойство сопряжённости.**  
Если β — корень M(x), то его «родственники» β^2, β^4, β^8, … (возведение в степень двойки) также являются корнями этого же полинома. Это происходит потому, что для GF(2^m) справедливо тождество (α+β)^2 = α^2 + β^2, и если M(β)=0, то M(β^2) = [M(β)]^2 = 0.

Это свойство позволяет эффективно группировать элементы поля при построении кодов БЧХ, где корни порождающего многочлена выбираются как последовательные степени примитивного элемента.

---

## 8. Применение в кодах БЧХ и Рида–Соломона

Поля Галуа являются основой для построения мощных кодов с большой корректирующей способностью:

- **Коды БЧХ (Bose–Chaudhuri–Hocquenghem):** задаются корнями порождающего многочлена в GF(2^m). Позволяют исправлять кратные ошибки.
- **Коды Рида–Соломона (Reed–Solomon):** недвоичные коды над GF(2^m), широко применяемые в системах хранения данных и цифровом телевидении.

---

## 9. Заключение

Циклические коды обладают богатой алгебраической структурой, которая делает их удобными для анализа и реализации. Полиномиальное представление позволяет использовать мощные методы теории полей Галуа для построения кодов с заданными корректирующими свойствами. Расширенные поля GF(2^m) являются естественной средой для создания недвоичных кодов, способных исправлять пакеты ошибок и работать в системах с высокой плотностью ошибок.
