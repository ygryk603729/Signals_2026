# Конспект лекции 1. Кан Игорь
**Обработка и интерпретация сигналов**

## Цель курса

Изучение теории передачи данных через каналы с помехами и способов канального кодирования, позволяющих добавлять избыточность для борьбы с ошибками.

Все данные, для которых существует возможность потери или искажения, всегда кодируются с целью уменьшения влияния этих искажений.

## 1. Упрощённая модель цифровой системы связи

Источник данных может быть:
- человек,
- флеш-накопитель,
- компакт-диск и т.п.

Схема модели:

Источник данных  
    ↓ (информационные символы)  
Кодер канала  
    ↓ (кодовые символы с избыточностью)  
Канал с шумом  
    ↓ (кодовые символы + ошибки)  
Декодер  
    ↓ (оценка информационных символов)  
Получатель

Пояснение:  
- Кодер канала добавляет избыточность для защиты от ошибок.  
- В полной системе перед ним может стоять кодер источника (сжатие), но в данном курсе основной акцент на канальном кодировании.

## 2. Основные допущения модели

1. Работаем с дискретными последовательностями.  
2. Информационная последовательность состоит из элементов поля GF(2) = {0, 1}.

Источник генерирует последовательность нулей и единиц. После кодирования получаем также битовые символы, но их количество увеличивается за счёт добавленной избыточности.

## 3. Двоичный симметричный канал (ДСК / BSC)

На вход канала последовательно подаются символы 0 и 1.

Поданный символ может быть принят неверно с вероятностью p — переходной вероятностью.

Схема переходов:

Вход → Канал → Выход  
0     → (1-p) → 0  
0     → p     → 1  
1     → p     → 0  
1     → (1-p) → 1

Если передавать один символ без избыточности, вероятность ошибки равна p.

## 4. Канальное кодирование

Процедура перевода информационных символов в кодовые символы называется канальным кодированием.

### Пример 1. Повторный (тройной) код

0 → 000  
1 → 111

- Скорость кода: R = 1/3  
- Исправляет одну ошибку  
- Декодирование — по правилу большинства

### Пример 2. Линейный (5,2)-код

00 → 00000  
01 → 10110  
10 → 01011  
11 → 11101

Свойства кода:  
- код линейный  
- исправляет одну ошибку  
- скорость кода R = k/n = 2/5

**Домашнее задание:**  
вычислить вероятность ошибки декодирования при p = 10^{-3}.

## 5. Теорема Шеннона (1948)

Теория информации делится на два направления:  
- кодирование источников (удаление избыточности)  
- канальное кодирование (добавление избыточности)

Пропускная способность двоичного симметричного канала:  

C = 1 - h2(p)  

где h2(p) — бинарная энтропия:  

h2(p) = -p * log2(p) - (1-p) * log2(1-p)

**Основное утверждение:**  
- Если скорость кода R < C, вероятность ошибки можно сделать сколь угодно малой (увеличивая длину кода).  
- Если R > C, надёжная передача невозможна.

## 6. Вес и расстояние Хэмминга

**Вес Хэмминга** ω(x) — число единиц в двоичном векторе x.  

**Расстояние Хэмминга** между двумя векторами x и y:  
d(x, y) = ω(x + y)   (сложение по модулю 2)  

Также: d(x, 0) = ω(x)

**Пример:**  
x = 001101 → ω(x) = 3  
y = 101001 → ω(y) = 3  
d(x, y) = 2

## 7. Минимальное расстояние кода

d_min = минимальное расстояние между любыми двумя различными кодовыми словами.

## 8. Исправляющая способность кода

t ≤ floor( (d_min - 1) / 2 )  

Код может гарантированно исправить до t ошибок.

## 9. Линейные коды

Код C называется линейным, если для любых двух кодовых слов x, y выполняется:  
x + y также принадлежит коду C.

Для линейных кодов:  
d_min = минимальный вес ненулевого кодового слова  
(минимальное расстояние равно минимальному ненулевому весу).

## 10. q-ичные линейные коды

Линейный (n, k)-код над полем GF(q) — это k-мерное подпространство пространства F_q^n.

**Пример:** q = 3, k = 2, n = 5  
Количество кодовых слов = q^k = 9

## 11. Порождающая матрица

Порождающая матрица G имеет размер k × n (каждая строка — базисный вектор).  

Информационное слово m = (m1, m2, ..., mk)  
Кодовое слово: c = m · G

## 12. Проверочная матрица

Проверочная матрица H имеет размер (n - k) × n.  
Для всех кодовых слов c должно выполняться условие:  
c · H^T = 0  
(или эквивалентно G · H^T = 0)

Это основное условие для проверки принадлежности слова коду.

## 13. Основные обозначения

- ω(x) — вес Хэмминга  
- d(x,y) — расстояние Хэмминга  
- d_min — минимальное расстояние кода  
- t — исправляющая способность  
- R = k/n — скорость кода  
- G — порождающая матрица  
- H — проверочная матрица
